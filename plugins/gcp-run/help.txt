CLOUD RUN

  status[:ENV]
    Show readiness and current revision of configured Cloud Run services.

  restart[:TARGET][:ENV]
    Create a ready revision using the deployed image. No build or Terraform apply.
    Requires single-container services with 100% untagged traffic following latest.

  logs:TARGET[:ENV]
    Follow Cloud Run service logs. Instance indexes are unsupported.

  shell:TARGET[:ENV]
    Connect using preview Cloud Run SSH (must be enabled). No instance indexes.
